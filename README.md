# NexusERP — Enterprise Resource Planning One-Page Application

NexusERP is a modern, responsive, high-performance enterprise resource planning (ERP) single-page application built with **plain HTML, Tailwind CSS, JavaScript (ES6+), and Chart.js**. 

Designed with a strict **Zero Build Step** constraint, this project requires no Webpack, Vite, Node.js compilation, or NPM installs—simply open `index.html` in any web browser or deploy directly to GitHub Pages, Netlify, or Vercel.

---

## 🚀 Key Features

1. **Executive Dashboard**: Real-time KPI metric cards (Revenue, Expenses, Supply Chain Fulfillment, Approvals) and an interactive enterprise transaction ledger with instant search and entry simulation.
2. **Interactive Analytics & Graphs**: Powered by Chart.js featuring Revenue vs. Expenses telemetry, Resource Allocation doughnut charts, Supply Chain throughput, and Server CPU load monitoring with period switchers (Monthly, Quarterly, Yearly).
3. **User Management & RBAC**: Active directory mock table with role-based access control (Administrator, Financial Controller, Supply Chain Manager, Standard Viewer) and interactive status toggles and user provisioning.
4. **Enterprise ROI Calculator**: Dynamic slider-based financial modeler calculating labor savings, ROI multipliers, and payback periods instantly based on employee count, wages, and legacy architecture.
5. **Modular Ecosystem**: Sections covering Financial Ledgers, Supply Chain & Inventory, and HR/Payroll Automation.

---

## 🛠️ Tech Stack
- **HTML5** & **Tailwind CSS** (via CDN for instant styling)
- **Vanilla JavaScript (ES6+)** for dynamic UI manipulation, modal controllers, filtering, and real-time data calculations
- **Chart.js** for responsive, high-performance data visualizations

## 📦 GitHub Deployment & Usage

### Local Testing
1. Clone or download this repository.
2. Open `index.html` directly in any web browser (Chrome, Safari, Firefox, Edge).

### GitHub Pages Deployment
1. Push all files (`index.html`, `script.js`, `README.md`) to your GitHub repository.
2. Navigate to your repository **Settings > Pages**.
3. Under **Branch**, select `main` (or `master`) and `/root`, then click **Save**.
4. Your Enterprise ERP one-page website will be live instantly!
